# YouTube Intro Skipper (refactor)

## Usage
1. Install system deps: `ffmpeg` and `chromaprint` (fpcalc)
2. Create and activate a virtualenv
3. `pip install -r requirements.txt`
4. Run:
   ```bash
   python main.py --reference-intro intro.m4a --urls-file urls.txt
````

See `main.py --help` for other commands.
